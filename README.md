# surface26.com

Static HTML/CSS site on GitHub Pages. No JavaScript, no build step.

## URL structure
Every page lives in a lowercase folder with an index.html (e.g. /why-us/index.html -> surface26.com/why-us/).
The old URLs (home.html, WhyUs.html, etc.) are tiny redirect files. Keep them so old links still work.

## Pages
The eight pages in the main menu, plus a 404 page. No extra pages (decided Oct 2026).

## Don't break
- Never rename ds/ to anything starting with an underscore.
- Never delete CNAME.
- index.html must exist at the root.
